# NAKHON NAYOK HEALTH DATA (หน้า Home)

หน้าหลักรวมแดชบอร์ดของสำนักงานสาธารณสุขจังหวัดนครนายก (ชุด NYK Health Analytics) เป็นไฟล์เดียว `index.html` สำหรับ GitHub Pages

## ข้อมูลที่ดึงมาแสดง

ดึงสดจาก MoPH Open Data ทุกครั้งที่เปิดหน้า (เก็บแคชในเบราว์เซอร์ 30 นาที) ใช้ตารางและวิธีคำนวณเดียวกับแดชบอร์ดย่อย

| ส่วน | ตาราง | นิยาม |
|---|---|---|
| ประชากร | s_persontype | ในพื้นที่ = TYPEAREA 1+3 หลัง cleansing · ไม่อยู่จริง = TYPEAREA 2 · นับซ้ำ = 1+3 ก่อน − หลัง cleansing |
| การป่วย | s_opd10_sex, s_opd10_sex15 | ครั้งผู้ป่วยนอก · กลุ่มโรคอันดับ 1 จาก 298 กลุ่ม · อายุ ≤ 15 ปี มีเฉพาะปีงบ 2567–2568 |
| การตาย | s_death_diag_sex_age | จำนวนราย · สาเหตุอันดับ 1 (ICD-10 3 หลัก) · R00–R99 = ไม่ชัดเจน · อำเภอตามที่ตั้งหน่วยบริการ |

## มาตรการความปลอดภัยที่ใส่ไว้ในหน้า

| เรื่อง | ทำอะไรไว้ |
|---|---|
| Content Security Policy (CSP) | อนุญาตให้รันเฉพาะสคริปต์และสไตล์ในไฟล์นี้ (ตรวจด้วย sha256) ห้ามโหลดสคริปต์จากที่อื่น ฝังกรอบได้เฉพาะ `https://apinyait.github.io` ดึงข้อมูลได้เฉพาะ `https://opendata.moph.go.th` |
| Trusted Types | ปิดการแทรก HTML ด้วย `innerHTML` ทั้งหน้า ลดความเสี่ยง XSS |
| กรอบแสดงแดชบอร์ด (iframe) | เปิดได้เฉพาะ 3 แดชบอร์ดที่กำหนดไว้ (allowlist) ใส่ `sandbox` ไม่ให้แดชบอร์ดเปลี่ยนหน้าหลักเอง และไม่ให้ใช้กล้อง/ไมค์/ตำแหน่ง |
| Clickjacking | ถ้าเว็บอื่นนำหน้านี้ไปฝัง หน้าจะถูกซ่อน |
| ลิงก์ภายนอก | `rel="noopener noreferrer"` และ Referrer-Policy `strict-origin-when-cross-origin` |
| ค่าที่เก็บในเครื่อง | เก็บแค่ธีม (สว่าง/มืด) และสถานะย่อเมนู ตรวจค่าก่อนใช้ทุกครั้ง ไม่เก็บข้อมูลส่วนบุคคล |
| ลิงก์แบบ `#hash` | รับเฉพาะชื่อแดชบอร์ดที่กำหนด ค่าอื่นกลับหน้าหลัก |
| HTTPS | `upgrade-insecure-requests` บังคับทุกคำขอเป็น HTTPS |
| ข้อมูลลับ | ไม่มี API key หรือรหัสผ่านในไฟล์ (MoPH Open Data ไม่ต้องใช้ key) |

## ข้อควรระวังเวลาแก้ไฟล์

CSP ตรวจสคริปต์และสไตล์ด้วยค่า hash ถ้าแก้โค้ดใน `<script>` หรือ `<style>` แม้แต่ตัวอักษรเดียว ต้องคำนวณ hash ใหม่ ไม่อย่างนั้นหน้าจะไม่ทำงาน
- แก้ข้อความใน HTML ทั่วไป (นอก `<script>`/`<style>`) ทำได้ตามปกติ
- ถ้าแก้สคริปต์/สไตล์ ให้ส่งให้ Claude สร้างไฟล์ใหม่ หรือรัน `python3 build.py template.html logo.txt index.html`

## ตั้งค่าบน GitHub ที่ควรทำ (ทำในเว็บ GitHub)
1. Settings → Pages → เปิด **Enforce HTTPS**
2. บัญชี GitHub → Settings → Password and authentication → เปิด **Two-factor authentication**
3. ห้ามอัปโหลดไฟล์ที่มีรหัสผ่าน โทเคน หรือข้อมูลรายบุคคลของผู้ป่วยขึ้น repo สาธารณะ
